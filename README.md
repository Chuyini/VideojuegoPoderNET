# Los Jefes de Chapultepec

Juego de 2 jugadores en la oficina de poderNET en Chapultepec. Pon a jalar a Debi, Toño, Diana, Luis, Felipe, Brenda y Suemmy, levanta la red en el NOC y demuestra quién es el jefe más cabrón.

## Cómo jugar

Abre `index.html` en el navegador. No necesita servidor ni instalar nada.

| | Moverse | Grito |
|---|---|---|
| Jugador 1 | W A S D | F o Espacio |
| Jugador 2 | Flechas | Enter o L |

- Empleado de flojo: +10
- Levantar la red: +25
- El grito despierta a los que estén cerca y aturde al otro jefe
- El café te hace correr más rápido
- Si la productividad llega a 0, los corren a los dos

Hecho con HTML, CSS y JavaScript (Canvas 2D + Web Audio), sin bibliotecas.
